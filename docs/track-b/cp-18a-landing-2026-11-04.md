## Interview answers

- **Why must the live builder never load the native LightGBM?** The GitHub runner has no `libomp`, so the first
  live-builder run issued nothing, with each day's cause recorded. The builder was then shown byte-identical with the
  native library refused and no local data present.
- **What did forcing every cause find?** A real double-close defect. A day left open in one run was closed twice
  before a later issuance, which `4ae383eb` fixed.
- **Why does a value-free leak scan use salted fingerprints and dump shapes, not token patterns?** It must run where no
  credential value may be read or stored, including public CI. Salted fingerprints match a value without holding it,
  and dump shapes catch an environment printed whole.
